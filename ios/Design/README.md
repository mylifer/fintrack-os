# Uygulama simgesi

`AppIcon-Mercek.svg` — Orbit simgesi ("Mercek"): grafik çizgisinin üstünde buzlu cam
büyüteç. Cam katmanlar altlarındaki sahneyi kırpıp bulanıklaştırır (Kum simgesindeki
teknik). 1024×1024 PNG'si `FinTrack/Assets.xcassets/AppIcon.appiconset/icon-1024.png`
(saydamlıksız, App Store gereği). SVG'yi Chromium'da 1024 px ekran görüntüsü alarak
PNG'ye çevirin; filtreler başka çeviricilerde farklı görünebilir.
